crypto-tss

Ed25519-compatible threshold Schnorr signatures.

Talk

  • Living with Asynchrony — distributed systems fundamentals and practical asynchronous distributed key generation. This deck is the normative specification of the ACSS construction.

Repository

  • README — the design space: FROST versus distributed Schnorr signatures, and five implementation stages up to an asynchronous nonce-DKG.
  • demo — Go examples for share generation and threshold signing.

Related

  • async.go — the asynchronous primitives the scheme is built on: Bracha's Reliable Broadcast and an hbACSS0 variant using Feldman's VSS.

This repository was previously published at iotaledger/crypto-tss, which has since been deleted. IOTA Smart Contracts still cites the original URL of the talk above as the specification of its ACSS implementation; that URL now returns 404, and this is the archived copy.
