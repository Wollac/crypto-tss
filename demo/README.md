# IOTA Threshold Ed25519 demo
This repository contains Go example implementations related to threshold signature schemes compatible with the IOTA protocol.

## Packages
It contains the following general packages:
- `sss` implements [Shamir's Secret Sharing](https://en.wikipedia.org/wiki/Shamir%27s_Secret_Sharing) to create [github.com/dedis/kyber](https://github.com/dedis/kyber) compatible shares of a secret.

## Examples
- `keygen` generates shares for one or multiple secrets.
- `nonce-sign` shows the creation of threshold signatures from precomputed nonce-shares.<br>
The nonce-shares must be valid shares of secret, e.g. generated by a DKG or the `keygen` example.<br>
